## 4. 五条异

1. **切点密度差 18.5 倍，且分布极不均。** 我们 5 处（70.51 / 81.18 / 84.01 / 99.31 / 103.85），**全部挤在 A① 的 33 秒里**；前奏 67.85 s 一镜、呐喊 14.6 s 一镜、间奏 **109.15 s 零切点**。原案 96 镜头 / 211.87 s ≈ 2.21 s 一切（二手）。**除 70.5–103.9 这 33 秒外，其余 212 s 没有任何镜头切换。**
2. **我们"灰"，原案"黑"。** 近黑像素 57.0% vs 81.8%；我们最暗的一帧也有 1.79%（103.85 s）；原案 8 格里最暗的一格 3.45%，而那一格 96.8% 的像素是近黑。我们的暗部是"暗蓝洗色"（`#323442` 占 6–19%），不是黑。
3. **字的亮度层级差一档。** 我们字顶到 V=168（琥珀）就停，`>200` 全片 0.108%；原案白字层 `>200` 0.312%、峰 1.835%。`>150` 5.2×。这不是"字少"，是**字不够亮**——加字号不如先提亮度。
4. **配色机制不同：我们换参数，原案换主色。** 两段主色同一对，色相锁 121；原案每场换主色（H110→171→2）并连底色一起换（`#050913`→`#42242E`）。所以我们两段之间没有"换台"感，只有"同一个台调了下亮度"。
5. **版式常量不同。** 我们的常量是**位置**（4 区全片不动），原案的常量是**外壳**（Discord chrome 不动，里面每场重画）。后果：原案能靠"换内容"制造切点，我们只能靠"换参数"——这也是 ① 里 212 秒零切点的根因。

## 5. 五条同

1. **底都是近黑**：没有任何一帧是亮底（我们最亮 11.04%，原案 8 格最亮 7.29%、2 原生帧 8.80%）。
2. **信息都压在"字"上**：两边最亮的元素都是排版（我们 98.68 s 的 0.84%；原案 `hit rate 98.8%` 格 1.835%），没有靠画面亮度叙事。
3. **都有"近黑 + 一个元素"的收束**：我们 81.18 s（2 帧 95.8% 近黑）/ t=80（内容 0.5%）；原案 r2c0（96.8% 近黑、彩色 0.65%）。这条是两边最像的地方。
4. **运动量都低**：我们 1 fps 相邻差分中位 1.66、33.5% 的秒对 <1.0、`<0.5` 占 15.9%；原案二手记录"运动量极低，绝大多数时间是打字机+消息追加"（plan/05 §3）。两边都没有连续运镜。
5. **都按段落切状态、不做连续演化**：我们五个段落是五套稳定值（亮度 5.61/6.69/9.14/9.62/8.70，近黑 72.7/64.0/49.4/48.1/47.5%）；原案 8 格是 8 套稳定构图。"帧是时间的分段函数"这条方法，两边一致。

## 6. 三条可以立刻改的（到秒）

### 改①　103.8–122.0 s（B①）：高潮改成"近白 + 砸满画幅"

- **现状**（统一 426×240 口径）：抽帧 t=120 的 `>200` **0.090%**、`>150` **0.572%**（原案同口径 1.835% / 2.380%）；字高 23.8% 画幅（114 px@480）；字色 `#A87F25`（V=168）；左屏三块面板仍在（原生 `dark5` 47.2%）。
- **做法**：`103.84–122.0` 期间左屏（CD/遥测/频谱）整体降到 6% 亮度；四个词在 **114.0 / 115.5 / 117.0 / 118.5 s** 依次落屏，每处一次 **2 帧快门黑**（复用现有 shutter，83 ms）；字号 ≥45% 画幅；颜色 `#FFF8E7`（V=255），不用琥珀。
- **判据**：118.0–120.0 s 的 `>200` 从 0.09% → **≥1.0%**，`>150` 从 0.57% → **≥2.0%**（原案同口径 2.380%）。
- **代价**：一套版式（4 个镜头），可砍掉 plan/05 §4 里"界面逐项点亮"的 8 个镜头。

### 改②　147.0 / 161.0 / 190.0 / 211.0 / 230.0 s：给间奏插五刀

- **现状**：136.6–245.75 共 109.15 s，**零切点**；1 fps 差分 162 s 为 **5.0**、212 s 为 **3.8**、230 s 为 **3.9**（阈值 6.5，均低于）。
- **做法**：五个位置各插"**2 帧快门黑 + 重新取景**"——内容不变，只换构图（推近山脊 / 低机位 / 把频谱隔离成整屏 / 俯视）。落点选在音乐结构上：147.0 是 14 秒骤静的起点、161.0 是回归、190.0 是碎块区起点、211.0 是全奏回归（plan/15 §1.4）。
- **判据**：切点 5 → 10，平均镜头 40.96 → **24.6 s**，最长镜头 109.15 → **30.9 s**；五处的 1 fps 差分都应 >8。
- **成本**：零新增内容，复用 `out/films/cut-shutter-v1.mp4` 已验过的做法。

### 改③　80.0–82.0 s：把这个气口压到真黑

- **现状**：80.0–81.0 s 近黑像素 **62.9%**、亮度 5.00–5.11%、`>200` 0.14%（那一行字是全场唯一亮点，但底不够黑）。对照原案空帧 96.8% 近黑。
- **做法**：80.0–82.0 s 把山脊/星野/遥测/频谱**全部降到 0**，只留那一行字 + 光标；字可提到 `#FFF8E7`。
- **判据**：该窗口 `<5%` 像素 **≥90%**、帧均值亮度 **≤3.0%**。
- **注**：81.18 s 已有 2 帧全黑（95.8% 近黑），说明管线本来就做得到，只是没保持——这是"改曲线"不是"改能力"。
