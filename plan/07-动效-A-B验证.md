## 1. 诊断对，处方有一半没跳出坑

v3 §5.1 的病理判断我完全同意：**"不是动得少，是动的东西没有状态"**。但那张"不做 / 改做"的表里，至少有两行仍然是被骂的同一类东西：

| v3 的处方 | 问题 |
|---|---|
| 匀速旋转 → **转速跟随音频**（安静时几乎停，全奏时快到糊） | 还是旋转。变速的平移仍然是平移，用户会第二次说"廉价"。 |
| 曲线笔尖平移 → **每帧变值** | 每帧都变＝噪声，不是信息。观众读不出"哪里变了"。 |

真正的分野不是"连续 vs 数值"，是下面三条。而且它们都比"换参数"便宜。

---

## 2. 三条原则

### 2.1 量化 > 连续

连续运动意味着"这是一个在动的装饰"；步进意味着"这是一台在计数的机器"。同一段位移，量化成 0.5 秒一跳，立刻就从"PPT 转场"变成"仪器在走数"。

所以碟不该"变速转"，该**每 0.5 秒跳一格**。滚动的字不该变速滚，该**整行跳**。

### 2.2 累积 > 清零

参考片最贵的地方不是"数字在变"，是**屏幕只增不减**——消息一条条堆上去，永不撤销。观众读到的是"这台机器在记录"。

我们现在的每一帧都是 `f(t)` 从零重画，**什么也不留**。所以哪怕动得再花，也只是"一张图在做体操"。

### 2.3 唯一 > 到处动

现在同一时刻有七处在动：山呼吸、星闪、ticker 滚、折线走、碟转、光柱脉动、雨落。

七处都在动，等于哪一处都不重要。**"贵"的最便宜的定义是：同一时刻只允许一处动。**

## 3. 做了什么（可回退）

`src/preview.py` 顶部加了一个开关：

```python
MOTION_V2 = True     # 翻成 False 就是旧版，逐帧可对比
```

三处改动：

| 位置 | 旧 | 新 |
|---|---|---|
| `cd_player()` 碟片相位 | `(t*40) % 360` 连续 | `(floor(t*2)*12) % 360` **每 0.5 s 跳 12°** |
| 底部 ticker | 一行以 `(t*46)` 匀速滚动，被卷走 | **追加式日志**：每 0.42 s 加一行，带递增编号 `0592 0593 0594`，旧的往上淡出、不消失 |
| `tk.line_chart()` | 滑窗，笔尖固定在右缘 | `mode="history"`：**从 0 秒到此刻的全部 RMS**，按像素分箱（一像素一均值），末尾 2 秒保留原始高亮 + 笔尖 |

`src/proof_motion.py` 用同一个 12 秒（266.31–278.31）渲两遍，OpenCV 编码（绕开坏掉的 ffmpeg）。

## 4. A/B 结论：一半更好，一半更差

| 项 | A 旧 | B 新 | 判 |
|---|---|---|---|
| ticker | 一行滚过，被裁断，看不出内容 | 三行编号日志，`0592→0594` 在涨 | **B 明显好**。"机器在算"这件事第一次成立 |
| 碟 | 光圈匀速转 | 每 0.5 秒跳一格 | **B 好**，转得"像仪表"而不是"像风扇" |
| RMS 折线 | 一条干净的滑窗曲线 | 266 秒压成一条密度不均的带 + 亮笔尖 | **各有代价**：B 有"记忆"，但糊、读不出趋势；A 干净但什么也没记住 |

**诚实的结论**：累积不是免费午餐。折线图这一处，B 版把"图表"变成了"记录仪"，信息对了、可读性掉了。下一步应该只压最近 30–60 秒（而不是全部 266 秒），并且在左侧留一个 `0000–0266` 的刻度，让"记忆"变成可读的跨度而不是一团毛刺。

## 5. 顺带发现两个真 bug（都比动效严重）

### 5.1 口令被塞进了歌词行

`B_new.mp4` 第 1 帧（266.33 s）左屏 LCD 显示：

```
（啊预备唱）谁从山中来带着兰花草
```

**"（啊预备唱）"是演出指令，不是唱词。** 它现在跟第一句歌词粘在一起，既破坏了"口令行是红色的 `>>` 提示"这个设计，也让整句在 384 px 里被挤到换行。

原因：LRC 里口令就是行内文本，`scene.py` 直接 `l["text"]` 拿去当歌词，没有拆。修法：解析时用正则把 `（…）` 摘出来，作为 `cue` 字段单独传。

**四条口令都要查**：`（啊预备唱）` `（第二步）` `（升key）` `（再升）`。

### 5.2 地形每 30 秒硬切一次

`scene.py` 第 132 行：

```python
seed = 3 + int(t // 30)
```

每过 30 秒，山脊的形状**整体换一次**——不是过渡，是跳。这比任何"平移特效"都更廉价，也更像故障。如果这是有意的"分段换景"，至少要做 8–12 帧的交叉溶解；如果不是有意的，应该全片一个 seed，只让振幅跟能量走（`amp_at` 已经在做这件事了）。
