## 1. 这个项目是什么

给张雨生《再见 兰花草!》（1994，专辑《卡拉OK·台北·我》末曲，6:35）做一支**代码逐帧生成**的 TUI 风格同人 MV。

- 帧 = 时间的纯函数（`frame(t)`），24 fps，1280×720，全片约 9 496 帧。
- 左屏：一台 **CD 播放机**（曲目信息为视觉重心）；右屏：歌里那座山 + 仪器读数。
- 全片主线：**改写**——A① 的 36 秒里发生四次文本改写（`我`→`谁` 等），第五次是本片自身，永远没写完。
- 结尾：386.5 `GAME SET` + `REWRITE 05` 空行 → 387.0 硬切 → 3% 黑 + 光标。

## 5. 新数据 A：解析视频 OCR（**尚未进入任何文档**）

来源：B 站解析视频《张雨生〈再见 兰花草〉解析》，391.7 s，up 主口播 + 字幕。
本机新模型**不能读图**，所以走 OCR：`rapidocr-onnxruntime` → `out/analysis-video-ocr.txt`（39 条，每 4 s 采样一帧，裁剪中央字幕带）。

### 5.1 前奏 0–67.85

| 时间 | 字幕要点 |
|---|---|
| 10–30 | 开头**小提琴**令人惊悚地展开；随着拉动，鼓和吉他来一记重击；后段小提琴转向**忧伤** |
| 42–50 | **钢琴、提琴、电吉他同节奏叠进**，"层层递进" |
| 54–66 | **电吉他**进入，极具破坏力；小提琴再现，作为伴奏**引出人声** |

→ **前奏不是"空山"，是四种乐器逐层叠加**。我们原来的"前奏 = 一个字长成山"缺少层次依据，应改成"四层乐器依次点亮"。

### 5.2 B① 与呐喊

| 时间 | 字幕要点 |
|---|---|
| 106–118 | 吉他、笔 = 创作者需要的东西；翅膀、空间 = 想做自己的音乐；**要证明自己不是被资本包装的偶像** |
| 126 | **随着鼓的重击，宝哥发出高亢响亮的呐喊** |
| 134–142 | 呐喊结束，电吉他与鼓收尾，一切化为寂静，"接下来是神乎其神的间奏" |

→ **B① 实际延续到约 134 秒**（含呐喊与收尾），我们的时间轴把它截在 122.0，**早了约 12 秒**。这条需要与分轨数据一起决定是否重切。

### 5.3 间奏（这是我们最缺的段落命名）

| 时间 | 字幕要点 | 对应我们的分轨（§6） |
|---|---|---|
| 150–162 | **细小的钢琴声**，风格像**巴赫的巴洛克音乐** | 147–162：只剩 `other`（钢琴归在 other） |
| 166–186 | **小提琴与钢琴交互进行** | 162–190：只有 `other` |
| 194–206 | "最神的一段"：**贝斯清晰可闻，每次贝斯出现电吉他都以不同方式咆哮** | 190–212：drums/bass 回归 |
| 210–242 | 贝斯与电吉他对话结束，**电吉他尽情咆哮** | 212–242：全奏，鼓最响 |

→ 间奏的五个段落现在**有了乐器名字**，可以按乐器设计画面，而不是按能量高低抽象处理。

### 5.4 后段

| 时间 | 字幕要点 |
|---|---|
| 246–258 | 许久不见的人声再现，**和声更明显** |
| 266–274 | 宝哥像**指挥员指挥大合唱乐团**，歌剧色彩，"**中国人的波西米亚狂想曲**" |
| 314 | **升 key 意味着情绪再次高涨** |
| 326 | 和声越来越明显，听感很丰富 |
| 338 | **最后一次升 key，情绪达到最高峰** |
| 382–386 | "结尾结束得很仓促……这个收尾我不是很喜欢" |

→ 与我们的结论一致：顶点在 A③；结尾是硬收。
→ "中国人的波西米亚狂想曲"这条类比**有出处了**（此前 03 文档只标为"乐评常见类比"）。
