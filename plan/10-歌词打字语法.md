# 歌词语法定案：打字 + 下划线 + 笔尖光标

> 2026-10-26 · 导演定调："不用写出来，用钢笔尖形状，以下划线的方式打出歌词，跟具有代码感，后续可以照着这种方向。波峰图也要读取音频，这是基底。"

---

## 1. 定案

**不做手写体。** 歌词是**打出来的**：一个字一个字整字出现，唯一连续移动的是那条下划线，笔尖停在线的末端。

这样既有"笔在写"的痕迹，又保住了机器的语汇——它像编辑器里的光标，不像书法。**楷体退场，改用与界面同一套黑体**；笔是画面里唯一"人"的东西，而且它只是一个形状。

---

## 2. 实现

```python
tk.pen_typed(img, xy, s, font, color, progress, alpha=0.95, nib=True, underline=AMBER)
```

| 元素 | 做法 |
|---|---|
| 正文 | `s[:n]` 整字绘出，`n = int(progress * len(s))` |
| 下划线 | 从行首到光标，**淡的一条**（琥珀 40%） |
| 笔尖下那段 | 光标前 26 px 加深到 80%——那是"刚写过的墨还没干" |
| 笔尖 | 亮尖 + 银灰笔身 + 一道暗缝，高约 24 px，随光标移动 |
| 进度 | 由 `scene` 按行时长算：`(t - 行起) / (行距 * 0.86)`，留 14% 余量让它写完再换行 |

**仍是 `frame = f(t)`**：不读上一帧，任何一帧可以单独重渲。

## 5. 两个冲突（需要处理）

### 5.1 笔和改写抢同一块屏幕

`v2-01-typing-early.png`（68.6 s）暴露的：A① 第一句 67.85 起打，`REWRITE_HOLD = 2.6` 秒，于是**刚打到第 3 个字就被改写 diff 整块顶掉**，笔尖消失。

观众看到的是"字写了一半，突然变成对照表"，像故障而不像设计。

**建议**：改写不要覆盖整行，改成**在已打完的句子上就地动**——先用笔打完（约 3.5 秒），再划掉"我"、写上"谁"。这样"写"和"改"是先后关系，不是抢位。代价是这一行要多留 1 秒，需要重新排 A① 的 36 秒预算。

### 5.2 A③ 还是旧的那五朵雏菊

`v2-05-A3-check.png`（320 s）里，五朵等距、同高、同大小的白瓣圆花——就是 `tk.flower()` 的六圆瓣菊。**歌叫兰花草，A③ 高潮却是一片菊花。**

换成 `tk.orchid()` 不是简单替换：现在 `flower_count=5` 是等距排布，而"一整片兰"需要另一套分布（高低错落、前后遮挡、盆可以只露一半）。这块要单独做，不建议顺手改。
