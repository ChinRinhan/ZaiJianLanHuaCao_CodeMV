## 0. 一句话

GAME SET 卡上那四行散字删干净，只剩大标 + 一条空行 + 光标；6:30 之后换成
**这台机器的最后一段打印**：同人署名 + 三个模型接在 CH 1–6 后面当 CH 07/08/09，
各自的官方 mark 抽成**真实轮廓**画出来（不是抽象化的像素块）。

## 1. 先确认"飘着"是什么

导演说的"多余字符"是 `ending_frame` 画在卡上的四行小字：

| 位置 | 内容 | 处置 |
|---|---|---|
| 左上 (64,40) | `LASER KARAOKE // LD-1994` | **删**（品牌已由 `> CREDITS` 那一段承担）|
| 中左 (64,372) | `REWRITE 05`（红） | **删**（剧情里是"第 5 次改写"，片尾读起来是残留）|
| 左下 (64,596) | `再见 兰花草` | **删**（歌名搬进 credits 的"原作/演唱"行）|
| 左下 (64,640) | `261026 0353` | **删**（时间戳残码）|

顺手量了一下：389.60 与 390.40 两帧**逐像素 0 差异**（max diff 1.0，>8 的像素 0 个），
所以它们不是"在动"，是散在画面上——删掉就干净了。

## 2. 为什么不做"片尾滚动字幕"

这片子从头到尾是**一台 1994 年激光卡拉OK机的界面**。所以 credits 做成
**这台机器打印出来的最后一段系统信息**：等宽字、琥珀色、`> ` 提示符、逐字打出（plan/10 的语法）。
滚动字幕属于另一种片子，一进来就出戏。

## 3. 制作人员一栏：STAFF（人 + 三个通道）

导演（01:1x）：「三个模型也是『制作人员』，上面应该给一栏」——对。三个模型挂在面板上却没有
抬头，读起来像"顺便列了三家厂商"。加一栏 **STAFF / 制作人员**（导演 01:2x 选 D 案：「STAFF 表确实是很老派」——
这部片子就是一台 1994 年的机器，老派是对的），人排在第一位，三个模型是同一栏里的
三条通道：

```
> CREDITS
同人作品 · 纯代码 MV
1994 LASER KARAOKE STYLE  ·  NO FOOTAGE — EVERY FRAME IS CODE
原作 / 演唱    张雨生《再见 兰花草》
────────────────────────────────────────────
STAFF           制作人员
OPERATOR        ■  RedStar_ChinRinhan
CH 07   [鲸鱼]     DeepSeek-V4.1-flash
CH 08   [波形 M]   MiniMax-M3.1-flash
CH 09   [字标]     Mimo-V2.6-Pro
────────────────────────────────────────────
[ 谢谢收听 ]
```

**为什么是 STAFF 而不是 MODELS / TOOLS**：
- `MODELS` 只说"这些是模型"，没回答"模型在这片子里算什么"——导演的意思正是"算制作人员"；
- `TOOLS` 把三个模型降成工具，跟"制作人员"相反，而且这部片子的调子不是"我用了几个工具"；
- `STAFF` 是**片尾表最老派的那个栏位**（导演原话：「STAFF 表确实是很老派」）——
  而这部片子从头到尾是一台 1994 年的机器，老派正好是它该有的口气。
  （先做的 `CREW` 是同义但更新的词，导演选了 `STAFF`。）

**人的那一格是光标块**：`OPERATOR` 没有 logo，就用从 GAME SET 卡一路留到现在的那个方块——
全片唯一"还在等"的东西，正好是操作员的位置。

**要不要给每个模型一个角色词**（CODE / LAYOUT / AUDIT 之类）：不编。谁做了什么只有导演知道，
给我一句我就填；不给就只留名字——名字是事实，角色是我猜的。

## 4. logo：用官方形状，不用"抽象"

**第一版做错了。** 我一开始把三个 mark 降采样成 26×13 的字形矩阵（块状像素画）。
导演（01:0x）：「这个程序化生成还是不太行，毕竟厂商 logo 是准确信息，这个太抽象了」——
说得对：厂商 logo 是**事实**，不是风格素材。抽象化的鲸鱼等于把事实改掉了。

**现在**：从官方标识的矢量/位图源抽出**真实轮廓**，归一化成 0..1000 的整数点集写进
`src/logos.py`，渲染时用 `ImageDraw.polygon` 填——形状是官方那条鲸鱼、那个波形、那行字，
而仓库里**仍然没有一个图片文件**（画面上每一块颜色都是代码按点集填的），
所以片尾那句「EVERY FRAME IS CODE」还是成立的。

| 模型 | 官方源 | 抽出来的轮廓 |
|---|---|---|
| DeepSeek | Simple Icons 的 deepseek（官方鲸鱼，#5786FE）| 1 个外轮廓 + **3 个洞**（眼睛在里面），181 点 |
| MiniMax | Simple Icons 的 minimax（官方波形 M，#E73562）| 2 个外轮廓，179 点 |
| MiMo | XiaomiMiMo 的 GitHub 组织头像（官方字标 "Xiaomi MIMO"）| 15 个外轮廓 + 2 个洞，253 点，宽高比 7.83 |

做法（构建期跑一次，渲染时只读数据）：`src/probes/make_logos.py` ——
resvg 把 SVG 栅格化到 1024 px → OpenCV `RETR_CCOMP` 抽外轮廓/洞 → Douglas-Peucker 简化
（1.6 px 容差）→ 归一化。**每个 logo 按自己的宽高比放**，不拉伸：图形标高 52 px，
字标按宽度吃 150 px（高约 19 px）。

## 6. 顺手修掉一个真 bug：谢谢收听是豆腐块

`[ 谢谢收听 ]` 原来用 `font(tk.MONO, 15)`（consola）画——**consola 没有中文字形**，
渲染出来是 `[ ▯▯▯▯ ]`。这条尾巴以前从来没播到（见 plan/34 §2 的分支顺序 bug），
所以这个豆腐块一直没暴露。credits 和 `black_frame` 两处都改成 `tk.CJK`。

## 8. 还可以改的

1. **措辞**：现在的主标是「同人作品 · 纯代码 MV」，副标「1994 LASER KARAOKE STYLE ·
   NO FOOTAGE — EVERY FRAME IS CODE」。要换成别的说法只改 `credits_frame` 里那两行。
2. **logo 大小**：`logos.draw(..., px=4)` → 3 更精致、5 更醒目。
3. **要不要保留最后的黑场**：现在 395.10 之后是纯黑（0.57 s），不留光标。
   想留光标就把 `black_frame(..., cursor_on=...)` 打开，但要另给一个不与面板冲突的位置。
