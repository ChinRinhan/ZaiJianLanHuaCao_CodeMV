左边是"机器的标签面板"，右边是唱片套：

- `LASER KARAOKE // LD-1994` + 刻度尺（片子每个面板都有）
- 大标题「再见 兰花草」+ `张雨生 ·《卡拉OK·台北·我》· 1994 · 6:35`
- 「同人作品 · 纯代码 MV」+ `EVERY FRAME IS CODE · NO FOOTAGE · 1280×720 · 24 FPS`
- **中段那道波形是这首歌自己的包络**（ffmpeg 解 4 kHz 单声道，120 块 RMS 归一化）——
  不是装饰，和片子里每条曲线一样是量出来的
- 底部 `STAFF  RedStar_ChinRinhan` + `CH 07/08/09` 三个模型 + `[ PLAY ]` 芯片
- 右边唱片套：角标 + 细边 + 边缘暗角 + `LD-1994 · SIDE A · TRACK 13` + `© 1994 飛碟唱片 / 原版封面`

## 4. 视频简介

### 完整版（B 站）

```
同人作品 · 纯代码 MV｜张雨生《再见 兰花草》
（1994，《卡拉OK·台北·我》末曲，6:35）

这台机器叫 LD-1994：一块屏幕、一台激光唱片机、一个还没唱完的卡拉OK。
全片 6 分 35 秒，1280×720 / 24fps——没有一张素材图，每一帧都是代码按时间 t 算出来的。

画面里没有一处是"估"的：
· 逐字起音（每个字什么时候落）
· 逐句响度（哪句唱得更响，光带就更粗）
· 合唱人数与和声相对电平（用原曲 17 轨分轨量出来，第二次宣言时和声涌上来是事实，不是设计）
· 连片尾那道波形，都是这首歌自己的包络

画面语法是 1994 年的 TUI：等宽字、琥珀色、刻度尺、电平条、光标。
结尾是这台机器自己的关屏。

原作 / 演唱：张雨生
```
