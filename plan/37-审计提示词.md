## 1. 项目是什么

张雨生《再见 兰花草》（1994，专辑《卡拉OK·台北·我》末曲，6:35）的**代码逐帧生成** TUI 风格同人 MV。
一台虚构的 1994 年激光卡拉OK机的界面：左边是唱片机面板，右边是"世界"，整片 1280×720 / 24 fps / 395.667 s。
**每一帧都是歌曲时间 `t` 的纯函数**，没有一张素材图。画面里的每个动态都由从原曲里量出来的数据驱动
（逐字起音、逐句响度、合唱人数、和声相对电平）。

关键文件：

| 路径 | 是什么 |
|---|---|
| `src/scene4.py` | 帧函数入口 `frame(t)`，片尾链（关屏 / GAME SET / credits）也在这里 |
| `src/layout4.py` | 四区版式与几乎所有画面元素 |
| `src/voices.py` | 实测数据 → 画面参数的桥 |
| `src/build.py` | 盖楼（按篇章渲染）/ 拼主文件 / 出 4K |
| `src/cover.py` | 封面生成（16:9 / 4:3 / 1:1） |
| `src/logos.py` | 三个模型标识的**轮廓点集**（由官方标识抽出，不是位图） |

| `out/film-v2.mp4` | 成片（720p）· `out/film_4k.mp4` 是 4K |
