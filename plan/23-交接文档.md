## 4. 架构：一块东西的三种形态

整个第二篇章现在围绕**一个矩形**（器乐格 / `zones(cell_px=)`）组织，全部用**画面坐标**：

| 时刻 | 宽度 | 形态 |
|---|---|---|
| 83.35 | 292 | 三条轨（吉他/鼓/贝斯逐个加入） |
| 102.4 | →640 | 实体列塌成灯条，世界让位 |
| 103.84 | 640 | **一张占满整列的表**，四句「给我」砸进去 |
| 112.6 | →292 | 表从顶部**卷起**成底部五格条，三轨回到上方 |
| 117.39 | 292 | 05 写 `02:25`；表盘中生 |
| 118.6 | 292 | 表退掉，轨接管 |
| 136.6+ | 292 | **六轨常驻**（间奏） |
| 243.6–245 | →0 | 收；实体 244.2–245.8 长回 512 |

**关键函数**
- `scene4._cell_w(t)` 宽度包络 · `_form_collapse(t)` 实体让位 · `_cell_state(t)` 轨内容
- `layout4.zones(collapse, mode, cell, cell_px)` — **ops 列钉死在右边缘**（不能用 `cx1+GAP`）
- `instruments.cellpanel(img, rect, t, tracks=..., solo=...)` — 多轨渲染
- `layout4._dial(...)` 双环表盘 · `scene4._roll(...)` 机械计数器

## 7. 今天踩的坑（都会再踩，务必看）

1. **`build.py all` ≠ 盖楼**。导演说"盖楼"= 只重拼（`join`）。今天误跑 `all`，把 4 个未审
   篇章渲进主文件，花了 11 分钟，回退重来。
2. **`str.replace` 不匹配会静默通过**。今天有一次"改了钢琴进场"其实没改到，白渲两次楼层。
   **所有批量文本替换必须 `assert old in s`。**
3. **单位错**：鼓的步进格拿**拍号**比**秒**，16 格永远不亮。
4. **`zones()` 的 ops 不能跟着 content 走**：器乐格插进来后 SCORE 被拉成 728 px 长条。
5. **表单不能只占一列中间**：第一版是 640×576 面板里一条 124 px 的横带，三分之二空着。
6. **涟漪画在 h*0.74** 落在山脊轮廓下面的黑区，一帧都看不见 → 挪到 0.645。
7. **归一化要用权重和**：`len(steps)**0.62` 一秒顶到天花板，阶梯后面全平。
8. **一个元素一次只做一件事**：3:10–3:30 和 3:32 用过同一套语言（涟漪+螺旋+环），
   两边一样吵，solo 就凸显不出来。
9. **`_undo_at` 被区块替换吞掉过三次**——已挪到 `scene4.py` 文件末尾，别再放中间。

## 9. 给下一个 agent 的三句话

1. **先量再改**。今天每一次"我觉得"都被数据打回过：吉他是脉冲不是斜坡、吉他和贝斯
   大部分时间同时在响（"对答"不成立）、137–145 是第二座峰不是余音。
