## 1. 源码里那三条，我们一条都没有

### ① 全片只有一个时钟，而且是指数衰减脉冲

`film/tui_pv_world_execute_20260926/full/engine.py:66`

```python
def pulse(t, decay=0.14):
    return math.exp(-(t - beat_t(beat_index(t))) / decay)
```

每拍从 1.0 指数掉到 0，衰减常数 0.14 秒。界面上凡是"亮一下"的东西都乘这个值——**它们在同一拍上一起亮，然后一起暗**。

我们的做法：每个元素各有一条自己的线性斜坡（`_ramp` / smoothstep）。**七条互不相干的斜坡，就是"没有配合"。**

### ② 文字落在唱词的起音上，不落在句子的均分上

`continuity_full_v2/words.py` 的关键两个常数：

```python
MAX_TYPE = 0.25   # 一个词最多 0.25 秒打完，短词整词落拍
MIN_TYPE = 0.06
```

而且时间来自**强制对齐**的逐词时间表（Demucs 分离人声 + CTC 对齐）。每个字出现在它被唱出来的那一刻。

我们的做法：`progress = (t - 行起) / (行距 × 0.86)`，然后在句宽里均分。**字数是均分的，唱不是均分的**——所以文字永远比嗓子快半拍或慢半拍。

### ③ 每个字落地前有 80 ms 的"解析"过程

```python
SETTLE = 0.08  # a letter flickers through random glyphs this long after it comes out, then holds
```

字先在屏幕上乱跳，然后定住。加上缓动库里的 `ease_back`（过冲回弹），所以每个动作都是"冲进去、弹一下、锁死"。

我们只有 `smoothstep`——**到位就停，没有任何回弹**。这是"生硬"两个字最直接的来源。

## 3. 和仓库还差什么（诚实清单）

1. **逐字时间是推的，不是对齐的**。仓库用 Demucs + CTC 做强制对齐；我们只有行级 LRC，逐字时间是从行宽推到网格上的。**拍子对，字对不齐**。要做准，得跑一次强制对齐（本机没有模型）。
2. **他们 96 个镜头 / 211.9 秒 ≈ 每 2.2 秒切一次**；我们的 A① 是 **36 秒一镜到底**。这不是动效问题，是剪辑问题——但"生硬"有一半来自这里：没有镜头切换，观众只能盯着同一个构图看 36 秒。
3. **`pulse` 目前只挂在仪表板外框上**。曲目框、边框、ticker、遥测字符都还没接。仓库是**全部**接的。
4. **没有 `ease_back`**。过冲回弹还没实现，只做了"落定闪动"。

## 4. 顺带发现的一个 bug

`sanity-150.png`（间奏 147–161 的骤静）里，左屏还挂着上一句"我给你"——**间奏期间歌词没有清空**。`line_at()` 会一直返回最后一行直到下一行开始，中间 124 秒都在显示旧歌词。

修法：句尾到下一句之间超过 `BREAK = 2.0` 秒时，本句在尾音后一拍停住，再用一拍淡出（仓库的 `words.py:57` 就是这么写的）。我们没做这一步。
