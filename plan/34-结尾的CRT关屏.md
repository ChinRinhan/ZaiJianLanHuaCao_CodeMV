## 0. 一句话

386.5 原来是一帧**硬切**到 GAME SET 卡。现在换成一次真正的 CRT 关屏：
画面塌成一条亮线（行扭 + 亮带从下往上扫出）→ 亮线缩成一个点 → 点带余辉抖一下灭掉 →
黑管上浮出 GAME SET → 卡片退场，只剩光标和 `[ 谢谢收听 ]`。

## 2. 顺带发现的真 bug：这条尾巴根本没播

`scene4._plain_frame` 的分支顺序错了：

```python
if t >= 386.5:              # ← 先命中
    return preview.ending_frame(t, ...)
if t >= scene.END_CUT:      # END_CUT == 387.0，永远到不了
    return preview.black_frame(t, ...)
```

所以 386.5 之后**永远**返回卡片，`3% 黑 + 光标 + [ 谢谢收听 ]` 那一段从来没出现过。
plan/19 §2 row 4 记的结尾链是「GAME SET → 硬切 → 3% 黑 → 光标 → 谢谢收听」，
`preview.black_frame` 和 `scene.py` 里的旧路径都还是对的，只有 scene4 这条新路径把它挡掉了。

**修**：卡片只到 390.95，之后交回 `black_frame`。这条尾巴现在真的会播。

## 4. 为什么关屏落在 386.46 而不是 386.5

`scene.END_CUT = 387.0` 是**歌结束的那一帧**（之后音轨是静音）。画面应该和最后一个音一起死，
所以塌缩横跨最后 0.54 s（386.46 → 387.0），卡片落在"声音已经没了"的黑管上——
这也正好是导演要的"机器先死、遗言后显"。

## 5. 实现要点

- **行扭**：`_row_wobble` 按行做水平位移（`sin(y·0.052+phase)` + 一个更慢的副频），
  幅度随塌缩进度从 0 涨到 9 px。管子失去水平同步时就是这样——不是整帧抖，是**每一行抖得不一样**。
- **滚动亮带**：`_roll_band` 一条亮带从画面下方扫到上方（`yb = H·(1.10 − 1.25u)`），
  宽 22–56 px、峰值 alpha 0.46，随塌缩一起衰减。失去垂直同步的那一下。
- **线 → 点**：`_poff_line` 不依赖画面内容（这时内容已经读不出），只画一条亮线和琥珀色余晖。
  这样 387.0 前后（楼层 6/7 的接缝）不会因为"底图从画面换成卡片"而跳色。
- **余辉点**：`_poff_dot` 指数退 + 44 rad/s 的抖动，四层同心圆做出光晕。
- **卡片浮出**：`_card_float` 透明度 + 8 px 上浮，像黑管上慢慢显影的一行字。
- **光标不跟着卡片退场**：卡片是遗言，会消失；"还在等"的那个方块要留到最后。
  它和 `black_frame` 里那个光标是同一格（64,400–78,426），所以交接处不会闪一下。
- **`[ 谢谢收听 ]` 给 0.4 s 淡入**：原来是一帧硬出（整行字凭空出现）。既然这条尾巴现在
  真的会播到，就让它和卡片的退场接上。
